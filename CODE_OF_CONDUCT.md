# Code of conduct

Crosswire adopts the [Contributor Covenant Code of Conduct, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive; harassment, discrimination and personal attacks are not tolerated in any project space (issues, pull requests, discussions, or elsewhere when representing the project).

To report a concern, use the private channel described in [SECURITY.md](SECURITY.md) (a GitHub Security Advisory) and mark it as a conduct report. Reports are handled by the maintainer and kept confidential.
